取扱説明

基本の流れ

  • 左側の「基本設定」でキャンバスサイズを決めます。画像を読み込む前でも常に変更できます。
  • カテゴリごとに「画像登録」からPNGなどを追加し、チェックしたパーツがプレビューに重なります。
  • 単独レイヤーは1つだけ表示、組み合わせレイヤーは複数同時表示できます。カテゴリ上部のプルダウンで後から変更できます。
  • プレビュー上部の操作対象を選び、移動・サイズ・回転をドラッグまたは右側スライダーで調整します。

レイヤー・カテゴリ

  • カテゴリパネルの ↑ / ↓ で表示順を変更できます。下にあるものほど奥側、上にあるものほど手前側の扱いです。
  • カテゴリ削除を押すと、そのカテゴリと登録画像を削除できます。
  • 眉毛を髪の毛(手前)より前に出したい場合は、左側の専用チェックを使います。

テキスト・図形・枠

  • テキストレイヤーは文字、フォント、色、縁取り、影、縦書き/横書きなどを個別に設定できます。
  • テキストはチェックボックスで通常色 / グラデーションを切り替え、2色目・角度・幅を調整できます。
  • 図形レイヤーは○ / □ / △を選び、ベタ塗りまたはアウトラインのみで描画できます。
  • 図形は横幅・縦幅・比率維持・色・透明度・縁取り・影・角丸を調整できます。
  • 枠レイヤーは通常枠とクラシカル枠を切り替えできます。通常枠は4方向 / 上下のみ / 左右のみを選べます。
  • クラシカル枠はクラシカルA / B / Cから選び、4角素材の色・透明度・縁取り・ドロップシャドウを調整できます。
  • クラシカル枠の左右間隔 / 上下間隔はキャンバス中心基準で対称に動きます。枠サイズの上限は選択中デザインの原寸です。
  • テキスト・図形・枠は「立ち絵の背面 / 前面」を選べます。

エフェクト

  • エフェクトカードはカテゴリ一覧内で上下移動できます。
  • エフェクトは、そのカードより下にあるレイヤーだけに反映されます。
  • 色収差はRGB分離方式です。R / G / B の透明度合計が100%になるよう自動調整されます。
  • ダブルトーンは画像を輝度ベースで2色に置き換えるカラー効果です。暗部色と明部色を指定できます。

保存・読込・書き出し

  • JSON保存でプロジェクトをファイルとして保存できます。別ブラウザや別端末で続きから作業する場合に便利です。
  • キャッシュ保存はブラウザ内保存です。キャッシュ削除や環境変更で消える可能性があるため、重要な作業はJSON保存がおすすめです。
  • 「書き出し」からPNGを書き出せます。原寸または縦幅指定が選べます。
