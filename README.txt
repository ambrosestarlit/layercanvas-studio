Version 71
- Layer structure presets now switch all non-character layer groups independently per preset.
- Preset-scoped targets:
  - Background layers / background panel
  - Text layers
  - Shape layers
  - Hand material layers
  - Frame layers
  - Effect layers
- Character image parts continue to switch per preset as before.
- When switching the layer structure preset, the current preset's layers are saved and the target preset's own layers are loaded.
- JSON save/load and browser cache now preserve preset-specific layer states.
